# PaperFlow 使用说明

默认入口是 **Obsidian 左侧书本图标**，或命令面板中的 **PaperFlow：选择 Zotero 论文（按标题，生成或打开）**。输入标题的一部分，再选择论文即可。当前搜索不包含作者、标签、子笔记或全文。

连接本机个人文库后，每次打开选择器都会读取最新的一致性副本，不需要导出 BibTeX，也不需要 Zotero 云端 API key。它不是双向同步；Obsidian 的编辑不会回写 Zotero，Zotero 附件更新也不会自动重写旧笔记。

生成前先在 Zotero 搜索目标论文，确认父条目下有已下载且能提取文字的 PDF。优先使用包含正式论文全文的附件；有多份附件时当前取首个存在的本地 PDF，暂未提供附件选择器。缺失 PDF、只有远程占位文件或扫描件不会生成精读。

## 笔记怎样组织

显示标题是“方法名｜研究主题”，保留英文论文题名和书目信息。正文依次展开背景与任务、核心洞见、方法模块、实验表格、已有论文关系、批判性分析、结论和自测。模板文件在 `.obsidian/paperflow/templates/paper-summary.md`，可调整三级标题和写作提示；当前后端校验要求保留八个二级章节。

点击 `Zotero` 跳到父条目；点击 `p.N` 或图表出处跳到 PDF **物理第 N 页**，可能与期刊印刷页码不同。原文图默认是方法、结果和消融相关页的整页图，不保证自动定位到最佳图表。要精确裁剪，可配置 `.paperflow/figure-regions.json`：

```json
{
  "ABCD1234": [
    {"role":"method","page":3,"crop":[0.05,0.1,0.95,0.5],"label":"方法总览"}
  ]
}
```

坐标从页面左上角起，按宽高归一化；页码从 1 开始。裁剪名含 PDF hash 与坐标 hash，换图不会误用旧缓存。指定 `figure-regions` 会替代默认三类选页。

## 保留自己的阅读记录

把个人想法写在文末“我的阅读记录”，即 `<!-- PAPERFLOW:PERSONAL -->` 之后。重生成会保留该区域最新内容；属性中的个人字段、标签和阅读进度也保留。AI 区域的手动修改会在下一次主动重生成时被替换，应先移到个人区域。

生成过程中若你改了 AI 正文或属性，程序会停止合并，保留当前笔记；候选稿在 `.paperflow/state/<key>/`。成功重生成的旧版在 `.paperflow/history/<key>/`。不要删除保护标记。同一个 key 若出现多篇主笔记，先人工合并后再运行。

## 搜索 Zotero

需要全库搜索，先点 Zotero 左侧“我的文库”；若选中某个集合，搜索范围就是该集合。右上角搜索框的菜单可选择标题/创建者/年份、所有字段和标签、或所有内容。PDF 全文搜索依赖 Zotero 已下载并建立索引的附件。高级搜索适合按作者、年份、标签等组合条件查询。参见 [Zotero searching](https://www.zotero.org/support/searching)。

## 排错

- 选择器打不开：检查 Python 环境、Zotero 数据目录，运行项目 `scripts/doctor.py`。
- 缺全文：先补 PDF 或下载同步附件；不要把元数据导读当精读。
- 数据库持续变化：稍后重试。程序不会绕过锁写入原库。
- 模型失败：确认配置、上下文和输出预算；错误不会发布半篇笔记。
- 页图不是想要的图：使用上述裁剪配置，不把自动整页截图误称为图表识别。
- 想从 Zotero 右键启动：实验 Bridge 尚未完成安装验证，当前从 Obsidian 启动。
